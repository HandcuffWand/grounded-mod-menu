## 🧩 About

**Grounded helpers** is a curated list of Grounded open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource tracker, menu panel
- **Quality-of-Life Helpers** — crafting catalog, base layout notes, HUD tweaks
- **Research Notes** — survival routes and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Survival Helpers
- Resource Tracker — keep notes on nearby materials
- Show Interactables — visualize collectible nodes
- Route Notes — record and review exploration runs
- Movement Speed — adjust walk pace for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Item Catalog — browse gear, materials, mutations
- Custom Loadout Notes — organize armor and weapon sets
- HUD Clarity — improved visibility for status bars

### 🏋️ Base & Layout
- Base Planning Notes — segment study on any layout
- Build Snapping Notes — align structures in the editor
- Storage Buffer Notes — chain complex crafting maneuvers
